## 3. Индивидуальный проект

**Название:** Система учета подарков.

Проект ПР2 переработан без изменения предметной области. Словари подарков
заменены объектами классов `Gift` и `User`, а коллекции данных теперь имеют
типы `list[Gift]` и `list[User]`.

Класс `Gift` содержит атрибуты `id`, `name`, `recipient`, `price`,
`delivery_cost`, `delivery_date` и `is_purchased`. В классе реализованы:

- конструктор `__init__()`;
- `__str__()` для удобного вывода подарка;
- `total_cost()` и `is_within_budget()`;
- `order()` и `cancel_order()` для изменения состояния заказа;
- `status()` для определения статуса доставки;
- `from_data()` и `to_data()` для преобразования данных.

Функции обработки коллекции сохранены как обычные функции: поиск, фильтрация,
сортировка, добавление и поиск подарка по идентификатору. Это разделяет
ответственность объекта и операций над коллекцией. Модуль `storage.py` отвечает
за границу между объектной моделью и JSON, а `main.py` использует атрибуты и
методы `Gift` и `User`, не работая со словарями предметной области.

Класс `User` хранит `id`, `name` и `email`, а объект `Gift` содержит ссылку на
получателя в атрибуте `recipient`. В JSON эта связь представлена идентификатором
`recipient_id`.

В проекте используются три JSON-файла:

- `data/gifts.json` — сведения о подарках;
- `data/users.json` — сведения о пользователях;
- `data/settings.json` — настройки и бюджет приложения.

## 4. Результат работы

- основная сущность проекта представлена классом `Gift`;
- получатель представлен классом `User`;
- данные и поведение подарка объединены в объекте;
- коллекции приложения содержат объекты `Gift` и `User`;
- организована связь `Gift.recipient -> User`;
- реализованы `__init__()` и `__str__()`;
- добавлен classmethod `from_data()` для восстановления объектов из JSON;
- добавлены три JSON-файла: `gifts.json`, `users.json` и `settings.json`;
- реализована загрузка и сохранение объектов `Gift` и `User`;
- сохранены просмотр, поиск, проверка бюджета, заказ и отмена заказа;
- тесты адаптированы к объектной модели и дополнены проверкой JSON round-trip;
- выполнена проверка `pytest -q`: **12 passed**;
- выполнена проверка `flake8`: замечаний нет;
- README обновлен и отражает актуальную структуру проекта.

## 5. Вывод

В ходе ПР3 функциональная модель системы учета подарков преобразована в
